Geist Sans variable font from the published `geist@1.4.2` npm package:
`dist/fonts/geist-sans/Geist-Variable.woff2`, renamed to `GeistSans.woff2`.

Self-hosted through `next/font/local`; no external font requests or runtime package dependency.
Copyright and SIL Open Font License 1.1 are preserved in `OFL.txt`.

The font is preloaded with `font-display: block` to avoid visible fallback glyph swaps during its initial local load.
